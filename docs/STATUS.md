## Recent Fixes (2026-07-10)

- **ACP autodetect + init-failure diagnostics** — Three fixes to `internal/acp`. (1) Codex autodetect spec now prefers `codex-acp` (the standalone ACP adapter) over the bare `codex` binary, which on most machines is the OpenAI Codex CLI TUI and hangs the probe when spawned with no args. `commands: ["codex-acp", "codex"]` mirrors the existing `mistral-vibe` (`vibe-acp` → `vibe`) bridge-first pattern. (2) `startTransportLocked` now reads `transport.StderrTail()` before `Close()` on `Initialize` failure and appends it to the error (`initialize transport: ... (agent stderr: ...)`), so users see *why* the agent exited instead of a bare "peer disconnected before response". (3) `tryACPProvidersList` no longer discards stderr with `io.Discard`; it captures a 4 KiB tail via `ringBuffer` and appends it to the warning on `Initialize`/`providers/list` failure, explaining why a detected agent failed the ACP probe. `go test ./internal/acp/`, `go vet ./...`, `golangci-lint`, `go build` all clean.
- **MCP config backend (WI-1)** — Implemented the MCP server configuration backend per `docs/research/mcp-config-design.md`. New `internal/mcp` package stores a Claude Desktop–compatible `mcpServers` map in `~/.local-agent/mcp.json` (envelope with `$schema`/`version`/`mcpServers`; per-server `enabled` flag, nil => default-on). `ServerConfig` is a superset of the Claude/Cursor/Windsurf shape (stdio `command`/`args`/`env` map/`cwd`, http/sse `url`/`headers` map). `Load` returns an empty File (not nil) on missing file; `Save` writes atomically (temp + rename, mode 0600, dir 0700). `ToACP`/`ToACPSlice` translate to `acp.McpServer` at session-start time, converting the Claude-style `env`/`headers` maps to ACP's `[]EnvVariable`/`[]HttpHeader` arrays, expanding `${VAR}` env references against `os.Getenv`, and filtering by the agent's advertised `McpCapabilities` (stdio always supported; http/sse dropped unless the agent advertises the capability). Wired into `internal/acp`: `Transport` gained an `mcpServers` field + `SetMcpServers`; `Client` gained `SetMcpConfigPath` + `loadMcpServersLocked` called from `startTransportLocked` after `Initialize` returns the agent's `McpCapabilities` (missing file = no servers; parse error = log warning + no servers, never blocks session creation). REST API in `internal/server`: `GET /api/mcp` returns the raw on-disk JSON bytes verbatim (preserves user formatting; empty envelope on missing file), `PUT /api/mcp` validates by parsing into `mcp.File` then writes the raw bytes atomically (400 on parse error), `PATCH /api/mcp/servers/{name}` toggles a single server's `enabled` flag. Daemon wires `mcpConfigPath = ~/.local-agent/mcp.json` into both the ACP client and the server `Deps`. Tests in `internal/mcp` (16 cases) and `internal/server` (7 cases). `go test ./...`, `go vet`, `golangci-lint`, `go build` all clean. Frontend (CodeMirror JSON editor + enable/disable toggle) is a separate work item.

Build + eslint pass.

- **ACP spec compliance (Priority 1 + 2)** — Implemented all 7 items from `docs/plans/acp-spec-compliance.md`. (1.1) Context is now sent as structured `resource` ContentBlocks (uri, mimeType, text) instead of flattened markdown text; the pipeline returns `PromptResult{Text, Resources}` and `Transport.Prompt` builds `acp.ResourceBlock`s when the agent advertises `embeddedContext`, falling back to `ResourceLinkBlock + TextBlock` otherwise. (1.2) The agent's `stopReason` from the `session/prompt` response is captured and included in the final `StreamUpdate` event; the frontend displays non-normal reasons (max_tokens → "hit token limit", refusal → "refused", etc.). (1.3) Open file contents and editor selection are sent as resource blocks with every prompt via `OpenFilesResourceMiddleware`; the frontend reports selection via the existing `POST /api/sessions/{id}/context` endpoint (extended with a `selection` field); per-file (32 KiB) and aggregate (128 KiB) byte caps prevent context blowup. (2.1) `reject_always` auto-deny implemented in the permission manager with a deny cache mirroring the allow cache. (2.2) Terminal `env` variables are overlaid on the daemon environment and passed to subprocesses via `shell.Executor.WithEnv`. (2.3) Terminal signal termination detected via `syscall.WaitStatus` and signal name populated in `TerminalExitStatus.Signal`. (2.4) Protocol version pinned to `acp.ProtocolVersionNumber` (v1) in `InitializeRequest`. Tests in `internal/acp`, `internal/permissions`, `internal/shell`, `internal/server`.

## Recent Fixes (2026-07-06)

- **Image upload flow** — Users can now attach images to prompts via the paperclip button in the chat composer. Mode B (filesystem upload + URI reference, capability-gated inline fallback): new `internal/uploads` package stores validated uploads per-session under `~/.local-agent/uploads/{sessionID}/`, detecting format by magic bytes (PNG/JPEG/GIF/WebP) and writing the correct extension (avoids the mime-by-extension bugs in agent read-tool image pipelines). Two new REST endpoints: `POST /api/sessions/{id}/uploads` (multipart, 10 MB cap) and `GET /api/sessions/{id}/uploads/{uploadID}` (serves the file). `SendPrompt` signature extended to accept `[]Attachment`; the ACP transport builds `[]ContentBlock` capability-gated — when the agent advertises `PromptCapabilities.Image`, sends inline `ImageBlock` (base64) with a `Uri` hint; otherwise sends `ResourceLinkBlock` + a text instruction telling the agent to read the file (all agents MUST support resource links per ACP spec). File-read errors fall back to the resource-link path. `Event.Attachments` (references only, never blobs) persists to the event log so chat history renders thumbnails. Uploads are cleaned up on session close (`handleCloseSession` → `Uploads.RemoveSession`). Frontend: paperclip wired to a hidden multi-file input, preview chips with remove buttons in the composer, `api.uploadFile` (raw `fetch` for multipart), `sendPrompt` threads attachments, and `ChatMessageItem` renders 80×80 thumbnails (click to open raw). Note: Claude Code CLI has a documented gap delivering inline images even when `ImageBlock` is sent — the URI + resource-link fallback path is the robust one until that's fixed upstream. Tests in `internal/uploads`; runtime smoke verified upload→serve round-trip (byte-exact), bad-attachment-id 400, non-image 400.
- **Sliding-TTL device credential expiry** — Paired device credentials were permanent until revoked. Added a sliding inactivity window: `storedDevice.LastSeen` is renewed on each successful `ValidateCredential` (throttled to ≤1 disk write/min), and a credential older than `inactivityTTL` since last activity fails auth. Configurable via `CredentialInactivityTTLSeconds` (default 30 days; `0` disables). Wired through config → daemon → `cmd/app` `toDaemonConfig`. Migration backfills `LastSeen` from `PairedAt` for pre-existing devices. Tests in `internal/pairing`.
- **Light theme + shadcn foundation** — Added a real light palette (`:root`) alongside the dark palette (`.dark`) with a full semantic-token set (background/foreground/card/popover/primary/secondary/muted/accent/destructive/border/input/ring). New `src/lib/theme.ts` + `useTheme` hook manage `dark | light | system` (default dark); `main.tsx` applies the stored preference; the MobileSettings theme toggle is now functional (was dead UI). Installed shadcn primitives (`components/ui/`: button, select, dialog, dropdown-menu, popover) on Radix + `tw-animate-css`. Migrated all components off raw palette classes (`text-gray-*`, `bg-blue-*`, …) onto semantic tokens so both themes render correctly; ChatPanel/SettingsModal now use shadcn `Select`/`Dialog`. Resolves all 8 deferred `web-*` findings (see below).
- **Frontend hooks hardening** — `App.tsx` no longer calls `loadSessionEvents` during render (moved to a guarded effect + ref-tracked one-time load; ChatPanel agent/model restore no longer reads stale `selectedAgent`). `useBackend.ts` dropped its file-level `eslint-disable exhaustive-deps` (now a single justified targeted disable on the run-once mount effect) and bounds the in-memory event log at `MAX_EVENTS=5000` (eviction is safe — SQLite is source of truth and `loadSessionEvents` re-fetches).
- **Live file-change detection** — Files changed on disk for OPEN editor tabs now update the editor without a forced reload. Agent writes (`FileWritten`) and external edits refresh a clean tab silently; a tab with unsaved edits is flagged `changedOnDisk` with a "changed on disk" banner + Reload. New backend fs watcher (`internal/fswatch`, fsnotify) watches registered workspace roots (recursive, ignores `.git`/`node_modules`/etc.), suppresses the app's own writes, throttles repeats, and broadcasts `EventFileChangedOnDisk`; wired via new `workspace.Manager` `SetOnWrite`/`SetOnRegister`/`SetOnRemove` hooks and started/stopped in the daemon lifecycle. Tests in `internal/fswatch`.

## Recent Fixes (2026-06-30)

- **Permission prompt label hardening** — Some agents set a permission request's `ToolCall.Title` to an opaque tool-call ID (e.g. Claude `toolu_…`, OpenAI `call_…`, UUIDs, or random tokens like `muNNhDHjd`), which surfaced as "Permission Required / <id>". The previous heuristic only caught separator-free tokens and wrongly treated any `_`/`-` value as a real label. Now `looksLikeRawID` (backend `internal/acp/transport.go`, mirrored in frontend `ChatMessageItem.tsx`) recognizes ID-prefixed tokens, UUIDs, and long hex, falling back to a kind-derived label ("Run command", "Edit file", …). Covered by `TestLooksLikeRawID`.
- **Cross-platform test fix** — `TestExpandPathWindowsEnv` compared against `filepath.Join` (OS-dependent separator) and failed on Linux/macOS even though `expandWindowsEnv` only substitutes `%VAR%`. Expectation now uses the literal backslash path so it passes on all platforms.
- **Linux/macOS build script** — Added `build.sh` (counterpart to `build.ps1`): builds the frontend, re-embeds `internal/server/dist`, and compiles/installs the Go binary. Note: `internal/server/dist/` is gitignored, so a frontend build (`npm install && npm run build`) is required before `go build` can embed assets.

## What Works

- **Daemon + CLI** — start/stop/status/add-folder/pair/devices/revoke/logs. TLS support, config persistence. `remove-folder` and `list-folders` functional.
- **ACP client** — full Agent Client Protocol via `coder/acp-go-sdk`. Session lifecycle, streaming, enriched tool calls, thoughts/plans, permission policies, terminal support properly wired to shell executor. Verified E2E.
- **Pairing** — QR + mnemonic passcode, device credentials, revocation, and configurable TTL.
- **WebSocket sync** — real-time event broadcast, reconnection sync, keepalive pings, loopback auth bypass.
- **Permissions** — request/response flow, `allow_always`/`allow_session` policies (shell commands keyed by command text, not just session), audit log.
- **Event store** — SQLite WAL mode, append-only, query/replay. Busy timeout + connection pool configured.
- **File sync** — revision tracking (content hash), three-way merge, per-file locking, bounded LRU cache.
- **Frontend shell** — React 19 + Vite 8 + Tailwind v4 + shadcn/ui. Desktop/mobile layouts, chat, session list, file tree, editor tabs.
- **Chat** — streaming responses, markdown rendering, thoughts/plans/tool cards, conversation rename/delete/rebind, export, smart autoscroll.
- **Security hardening** — auth middleware on all API routes, WebSocket auth, ACP terminal cwd validation, workspace map race fix, sync/ACP/shell goroutine leak fixes, CLI TLS.

## Key Decisions

- Go module: `github.com/adama/local-agent`
- Frontend dir: `web/` (not `frontend/`)
- Dark theme default; Tailwind v4 `@theme inline` pattern
- Event-driven UI: all rendering derives from `AppEvent[]` stream
- SQLite via `modernc.org/sqlite` (pure-Go, no CGO)
- Must rebuild binary (`.\build.ps1`) after frontend changes — `go:embed` freezes frontend at compile time
- Note: `ACPClient.SendPrompt` signature change (adding `[]Attachment`) is a breaking change for out-of-tree implementers.
