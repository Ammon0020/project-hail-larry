# Vision

The Local Agent Interface is a self-hosted web code editor with AI built in. A lightweight daemon runs on the user's computer, serving a browser-based IDE to any device on the local network — phone, laptop, or tablet. The user pairs a device by scanning a QR code or entering a four-word passcode, then works in a familiar VS Code-style layout: an activity bar for switching between file explorer and search, a center editor with tabs and syntax highlighting (CodeMirror 6), and a right-side panel where an AI agent lives alongside the code. The app is not an AI itself; it is an ACP client that orchestrates any ACP-compatible agent (Claude Code, Codex CLI, Gemini CLI, and others), manages file operations, enforces permission prompts, and keeps everything synced across devices in real time.

In practice, the user opens the web UI, picks a harness and model from the right panel, and types instructions next to their code — not in a separate terminal, but in the same window where they're editing. The agent reads files, proposes edits, runs shell commands, and streams responses directly into the chat panel. When the agent edits a file, the editor updates live with a diff indicator; when the user edits a file, the host daemon handles revision tracking and three-way merging to prevent conflicts. Permission prompts appear inline — approve a shell command from your phone while the agent runs on your laptop. On mobile, the same capabilities are available through a bottom-nav layout that shows one panel at a time: explorer, editor, chat, or settings. The result is a coding experience where the AI is a first-class part of the editor, not a separate tool — fluid across devices, with all files and state safely on the host machine.
