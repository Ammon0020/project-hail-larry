- description: The tab close "X" is a `<span role="button" tabIndex={-1}>` nested inside the tab `<button>`. Two problems: (1) `tabIndex={-1}` removes it from the tab order, so a keyboard user can never focus it to close a tab — they must use a mouse. (2) A clickable element with `role="button"` nested inside a `<button>` is invalid HTML per the spec (interactive content cannot nest interactive content), and some browsers/AT may behave unpredictably. The same pattern is repeated for the "New chat" placeholder close (lines 215-228). Fix: move the close affordance outside the tab `<button>` (e.g. make the tab a `<div role="tab">` with a real `<button>` for close), or use a separate absolutely-positioned `<button>` sibling. At minimum, set `tabIndex={0}` and handle `onKeyDown` for Enter/Space so keyboard users can close tabs.
