A Go daemon that serves a browser-based IDE to devices on your local network. Pair devices, orchestrate AI agents via ACP, and edit code from anywhere on your LAN.

Usage:
  app [command]

Available Commands:
  add-folder        Register a workspace directory
  completion        Generate the autocompletion script for the specified shell
  devices           List paired devices
  help              Help about any command
  install-service   Register the daemon as a user service that starts on boot
  list-folders      List registered workspace directories
  logs              Print daemon logs (tail of the last 64KB)
  pair              Generate a QR code and passcode for device pairing
  remove-folder     Unregister a workspace directory by ID
  revoke            Revoke a paired device's access
  start             Start the Local Agent Interface daemon
  status            Show daemon status
  stop              Stop the running daemon
  uninstall-service Remove the system service registered by install-service

Flags:
  -h, --help   help for app

Use "app [command] --help" for more information about a command.
