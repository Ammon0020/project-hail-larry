# AGENTS.md

Rules and critical info posted at the start of every chat to create context. 

## Notes
- ACP defines its own standards - agent control should happen only through those standards. 
- Plans must be either summary (see docs/Blueprint.md) or executable in one branch under a single overarching work item (see docs/plans). 
- Run tests and linting before marking a task as complete. Ensure they pass completely clear. 
- Stay on task. If a test fails in another task, note it in docs/known-issues.md and move on - don't try to fix it.
